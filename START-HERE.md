# Start here

1. Unzip this folder, open a terminal in it, and run `claude` (Claude Code). It reads `CLAUDE.md` by itself.
2. Type anything (even "start"). It will read every document and picture, write `UNDERSTANDING.md`, ask you a few questions, and wait for you to say "go" before building anything.

Nothing needs to be typed into a prompt. If it jumps straight into coding, tell it: "Follow the Orientation block at the top of CLAUDE.md first."
