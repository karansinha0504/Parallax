# Mockups

**`parallax-tv-v7.html` and `parallax-phone-v7.html` are the exact UI to build, one to one.** See the top of `CLAUDE.md`.

Open in a browser (phone files open full screen on a phone). All content is placeholder.

- parallax-tv-v7.html: complete TV app including launcher and every screen, with the glass-slab focus (press G to toggle the old focus for comparison)
- parallax-phone-v7.html: complete phone app (no focus system, auto-cycling movie hero, glass only on overlays)
- parallax-launcher-v4.html: locked launcher layout
- parallax-launcher-v5.html: launcher with an icon-style switch (undecided)
- parallax-recents-v1.html: Recents stack (TV and phone)
- parallax-lyrics-seek-v1.html: lyrics view and slide-to-seek
- parallax-touches-v2.html: pane loader, fanning collections, card glow
- parallax-wordmark-v3.html: boot intro with the Heros wordmark

Not included (private, contain real posters): the *mylibrary files.
